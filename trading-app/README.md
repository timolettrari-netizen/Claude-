# Trade Begleiter (Handy-App)
Offline-fähige Web-App (PWA) fürs Handy: Positionsgrößen-Rechner (MES, MNQ, ES, NQ …), Trade-Journal, Tageslimit-Wächter und Dashboard (Equity-Kurve, Trefferquote, Profit-Faktor, Drawdown, P&L pro Tag/Instrument).
Daten bleiben lokal auf dem Gerät. Installieren: Seite im Safari/Chrome öffnen → „Zum Home-Bildschirm“.
